# AtomicForge

A guitar and songwriting toolkit. The `main` branch deploys ChordCraft v3 at the project root and the standalone AtomicForge tools alongside it through the workflow in `.github/workflows/pages.yml`.

Before the first deployment, set the repository's Pages source to **GitHub Actions** under **Settings → Pages**.

- ChordCraft v3: <https://airesponse.github.io/AtomicForge/>
